# AI Ad Creative Generator

A personal AI-powered workflow for generating short-form advertising concepts from a simple product brief.

## What it does

The project takes a basic product description and uses AI to generate:

- Advertising hooks
- Short-form video scripts
- Scene-by-scene visual suggestions
- Calls to action
- Social media captions

The goal is to reduce the repetitive work involved in developing initial creative concepts while keeping the human in control of the final creative direction.

## Workflow

Product brief
→ Automation workflow
→ AI generation
→ Structured creative output

## Example input

**Product:** Portable desk fan

**Target audience:** People working from home

**Main benefit:** Quiet cooling without taking up much desk space

## Example output

The AI generates multiple hooks, a short video script, suggested scenes, a CTA, and a social media caption based on the input.

## Tools

- Make — automation
- AI API — content generation
- GitHub — documentation and version control

## Why I built this

I wanted to explore how AI and automation can be combined to speed up creative workflows, while also learning more about APIs, structured outputs, and workflow design.

This is a personal project and does not contain proprietary data, assets, or workflows from my professional work.
